# Qijk Backend

This is the API behind the [qijk widget](https://github.com/JessengBijleng/Qijk-widget), a frontend that customers embed on their websites in an iframe so their visitors can create visualizations of kitchen wraps. This backend generates those visualizations with an AI, authorizes that a widget is allowed to use the API, and stores the requests visitors make.

Before you make changes, read `docs/overview.md`. It covers the project's goal, responsibilities, the constraints that come from serving an embedded widget, and the decisions that are still open.

## Docs

- `docs/overview.md`: goal, roles, responsibilities, constraints, glossary, decisions, open questions.
- `docs/development.md`: stack, scripts, project structure, conventions.

When you make a decision listed under "Open questions", or add something that changes the project's scope, update the docs in the same change.
